# Common-pistol recoil selection — pass 42

The trainer selects the wrong recoil-table entry for ordinary Deagle shots.
The current native server uses a supplied integer masked to six bits for
semiautomatic fire; the trainer instead uses its recovering floating recoil
index. That floating index remains necessary for accuracy recovery and must
not be replaced with the selected table entry.

Current changes accept an explicit supplied selector for replay. **Default
gameplay remains unchanged pending evidence for the native seed producer.**
An initial authored selector was rejected before release: besides lacking a
native mapping, it reused the first draw of spread's deterministic sequence
and introduced an unsupported correlation between recoil and spread radius.

32, 59, 41, 18, 11, 23, 12, 50 and 57. These indices are reconstructed from

The actual `WeaponRecovery` replay supplies each prior native punch anchor,
relative anchor time and inferred pre-shot accuracy index. It measures the

bundles the actual trainer recovery class and hashes every source input. Run

candidate, with identical extracted anchors. Baseline ignores the optional
argument; the candidate uses it. Every accepted/excluded shot and all eight
trajectory samples are retained. Do not replace the inferred selector with a

Run probes serially, with deployment inactive and at least 12 GiB available,
under `systemd-run --user --scope --quiet -p MemoryMax=512M -p MemorySwapMax=0
-p CPUQuota=100%`. Original local reports remain under
`native-audit/reports/core-shooting-next/` in the parent workspace.

## Remaining decision

The native immediate caller supplies its incoming integer before an optional
custom-seed branch; that branch changes a different global. A bounded follow-up
now identifies this field as `CBaseUserCmdPB.random_seed` (tag 10, int32) on
both the current client and server. The separate field proof checks 35
instructions and 8,026 selected bytes; it does not execute native code.

The upstream generator remains unbound. Following the retained input-base
constructor/hook returns to the already inspected conditional movement/view
override, which provides no generator. Imported `MD5_PseudoRandom`,
`RandomSeed` and `RandomInt` names do not establish which produces this field.
The investigation stops at that boundary. No guessed distribution or seed
mapping should become the production default.
